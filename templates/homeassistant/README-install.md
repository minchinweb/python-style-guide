## Installation

[![Open your Home Assistant instance and open this repository in HACS.](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=OWNER&repository=REPO&category=integration)

1. Click the button above. It opens this repository in HACS (the Marketplace
   in Home Assistant 2026.11 and later) on your own Home Assistant. If asked,
   confirm adding it as a custom repository.
2. Click **Download**, then restart Home Assistant.
3. Add the integration:
